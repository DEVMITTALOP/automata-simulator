1. Abstract & Problem Statement

In Formal Language Theory and Compiler Design, Non-Deterministic Finite Automata (NFA) provide a compact, human-intuitive way to model regular languages—especially when derived from regular expressions. However, NFAs cannot be directly executed in deterministic hardware or single-pass lexical analyzers without backtracking or tracking parallel state sets. Deterministic Finite Automata (DFA) eliminate this non-determinism, guaranteeing O(n) time complexity for scanning an input string of length n.

This project implements a lightweight, user-friendly Automata Simulator for NFA to DFA Conversion. Given any user-defined NFA (with optional ε-transitions), the simulator applies the Subset Construction (Powerset) Algorithm to compute reachable state subsets, generates equivalent DFA transition tables and state mappings, renders live state diagrams, and verifies equivalence through step-by-step string testing across both normal and edge cases.

2. Theoretical Foundation

2.1 Non-Deterministic Finite Automaton (NFA)

An NFA is formally defined as a 5-tuple M = (Q, Σ, δ, q0, F), where:

  • Q is a finite, non-empty set of states.
  • Σ is a finite set of input symbols (alphabet).
  • δ : Q × (Σ ∪ {ε}) → P(Q) is the transition function mapping a state and symbol (or ε) to a subset of states.
  • q0 ∈ Q is the initial (start) state.
  • F ⊆ Q is the set of accepting (final) states.

2.2 Deterministic Finite Automaton (DFA)

A DFA is formally defined as M' = (Q', Σ, δ', q0', F'), where every transition δ' : Q' × Σ → Q' maps a state and input symbol to exactly one destination state, with no ε-transitions.

2.3 Epsilon Closure (ε-closure) & Equivalence

By the Rabin–Scott Theorem, every NFA has an equivalent DFA recognizing the exact same language. For any set of states S ⊆ Q, ε-closure(S) is the set of all states reachable from states in S using zero or more ε-transitions:

q0' = ε-closure({q0})   |   F' = { S ∈ Q' ∣ S ∩ F ≠ ∅ }

3. Methodology & Subset Construction Algorithm

The simulator converts an input NFA into an equivalent DFA using Breadth-First exploration of reachable subsets starting from ε-closure({q0}). Unreachable powerset combinations are omitted, keeping the generated DFA minimal and clean. Empty transitions are routed to an explicit non-accepting DEAD (Φ) trap state when needed.

3.1 Algorithm Pseudocode

Algorithm: NFA_to_DFA_Subset_Construction(Q, Σ, δ, q0, F)
1.  initial_subset ← epsilon_closure({q0})
2.  Assign canonical label S0 ← initial_subset
3.  Q' ← {S0};  Queue ← [S0];  δ' ← {};  F' ← {}
4.  If (initial_subset ∩ F ≠ ∅) then add S0 to F'
5.  While Queue is not empty:
6.      curr_subset ← Dequeue(Queue)
7.      curr_name   ← LabelOf(curr_subset)
8.      For each symbol 'a' in Σ:
9.          move_set    ← ⋃ { δ(q, a) | q ∈ curr_subset }
10.         next_subset ← epsilon_closure(move_set)
11.         If next_subset is empty:
12.             next_name ← "DEAD"
13.         Else:
14.             If next_subset not in Q':
15.                 next_name ← "S" + counter++
16.                 Map next_name ↔ next_subset; Enqueue(Queue, next_subset)
17.                 If (next_subset ∩ F ≠ ∅) then add next_name to F'
18.             next_name ← LabelOf(next_subset)
19.         δ'(curr_name, a) ← next_name
20. Return DFA(Q', Σ, δ', S0, F')

3.2 Complexity Analysis

  • State Space: Worst-case |Q'| ≤ 2|Q|, though practical regular-language NFAs visit only a small fraction of reachable subsets.
  • String Simulation Time: Once converted, testing a string of length n runs in strict O(n) deterministic time.
